# 实时上下文、缓存诊断与 Token 流向

[English](../live-context.md) | **简体中文** · [← 返回 README](../../README.zh-CN.md)

本文介绍 AGY Lens 的三个单会话核心模块：**实时上下文（模块 #1）**、**Prompt Cache 诊断（模块 #2）**与**输入输出与 Token 流向（模块 #3）**。

---

## 1. 实时上下文构成（模块 #1）

以严格只读方式读取 Antigravity 本地 SQLite 对话数据库，实时呈现当前会话的上下文占用结构：

- **7 类上下文构成条**：将最新一轮输入拆分为 `System Prompt`、`Subagents`、`Skills`、`Plugins`、`Rules`、`Tools` 与 `Chat Messages`，展示各自 Token 数与占比。
- **自动压缩阈值标线**：结合当前模型的上下文上限绘制 `55%` / `80%` 标线，临近自动摘要或前缀重算时给出直观提示。
- **缓存余温状态**：根据距离上次回复的时间间隔，提示当前前缀缓存大概率仍热或已过期。
- **会话切换器**：在独立 Web 模式或多会话场景下，可通过统一的主题自定义下拉菜单在最近 Desktop 与 CLI 会话间自由切换。

## 2. Prompt Cache 诊断（模块 #2）

逐轮衡量当前会话的真实前缀缓存效果：

- **核心指标**：
  - **最近一轮命中率**：`cache_read / (cache_read + uncached_in)`。
  - **会话累计命中率**：全会话 Token 加权缓存复用率。
  - **缓存节省金额**：对比全量未缓存输入所节省的纯 API 等价费用。
- **近 15 轮输入构成柱图**：清晰区分 `Cache Read`、`Uncached`、`Cold`（首轮冷启动）与 `骤降`（命中率异常下跌）。

## 3. 输入输出与 Token 流向（模块 #3）

支持在 **`本会话` | `全局`** 视角间一键切换，将总 Token 拆分为 4 个独立桶：

- `未缓存输入（Uncached In）`
- `缓存读取（Cache Read）`
- `思考输出（Thinking Out）`
- `可见输出（Visible Out）`

同时汇总吞吐速率（`tok/hr`）、纯 API 等价费用与平均响应延迟（`TTFT` / 生成耗时）。
